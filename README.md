This project is a responsive game catalog.
Each weekly milestone adds or improves part of the site while keeping the project organized into separate folders.

Week 5:
prompt used: 
I need to update my CSS without changing how the website looks. 
Can you organize the stylesheet into the four layers: reset, base, layout, and components? 
Put resets in reset, default element styles and variables in base, page layout rules in layout, and things like navigation, filters, buttons, cards, and grids in components. 
Also, update the component styles to use native CSS nesting where it makes sense, including & for hover, focus, and pseudo-elements. 
Keep the existing design and functionality the same, and don’t add anything extra.
